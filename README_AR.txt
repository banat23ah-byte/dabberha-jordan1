دبّرها الأردن - النسخة الثالثة (تحسين التصميم)

الملفات:
- index.html: صفحة الموقع
- styles.css: التصميم المتجاوب
- app.js: البحث والتصنيفات وطلب إضافة النشاط
- manifest.json: معلومات تثبيت الموقع
- sw.js: ملفات التخزين المؤقت

طريقة التحديث على GitHub Pages:
1. فك ضغط dabberha_jordan_v3.zip على جهازك.
2. افتح مستودع GitHub الصحيح الذي ينشر موقعك.
3. Add file > Upload files.
4. ارفع الملفات الخمسة من داخل المجلد (وليس ملف ZIP).
5. اختر Commit directly to the main branch ثم اضغط Commit changes.
6. انتظر اكتمال النشر، ثم افتح الموقع واضغط Ctrl+F5.

ملاحظات مهمة:
- الأمثلة المعروضة تجريبية وليست عروضاً حقيقية مؤكدة.
- نموذج الإضافة يجهّز رسالة للنسخ فقط؛ لا توجد قاعدة بيانات أو لوحة إدارة ولا يتم إرسال الطلب تلقائياً.
- التصميم يستخدم خط Cairo من Google Fonts؛ إذا لم يتوفر الإنترنت سيستخدم المتصفح خطاً بديلاً.
