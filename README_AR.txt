دبّرها الأردن — النسخة التجريبية الأولى
========================================

ما الموجود؟
- واجهة عربية RTL متوافقة مع الموبايل والكمبيوتر.
- بحث وتصنيف حسب المدينة والنوع.
- أمثلة تجريبية للعروض والمطاعم والكافيهات والتسوق والخدمات.
- نموذج يجهّز نص طلب إضافة إعلان وينسخه.
- ملفات PWA أساسية للتثبيت عند استضافته على HTTPS.

مهم:
- البطاقات الموجودة حالياً أمثلة توضيحية فقط، وليست عروضاً حقيقية أو شراكات مؤكدة.
- نموذج الإعلان لا يرسل البيانات إلى خادم؛ إنه يجهّز النص داخل المتصفح فقط.
- لا توجد لوحة تحكم حقيقية أو قاعدة بيانات في هذه النسخة.
- لا تضع أرقاماً أو بيانات شخصية حقيقية قبل إعداد وسيلة تواصل وسياسة خصوصية مناسبة.

طريقة التشغيل على الكمبيوتر:
1. فك ضغط الملف dabberha_jordan.zip.
2. افتح مجلد dabberha_jordan.
3. افتح index.html بمتصفح حديث مثل Chrome أو Edge.
   ملاحظة: البحث والتصفية والنموذج تعمل محلياً. تثبيت PWA والعمل دون إنترنت يحتاج استضافة عبر HTTPS أو خادماً محلياً.

طريقة نشر مجانية مبدئية:
- يمكنك استخدام خدمة استضافة ثابتة مثل GitHub Pages أو Cloudflare Pages.
- ارفع ملفات المجلد كما هي، ثم اتبع تعليمات الخدمة لإنشاء موقع عام.
- اسم الموقع والرابط يعتمدان على الحساب والتوفر؛ لم يتم نشر الموقع تلقائياً.

الخطوة التالية:
استبدال الأمثلة ببيانات حقيقية موثقة، ثم إضافة طريقة تواصل رسمية ولوحة إدارة وقاعدة بيانات عند الحاجة.
