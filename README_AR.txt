دبّرها الأردن — الإصدار V5
============================

طريقة التحديث:
1) افتح مستودع GitHub الخاص بالموقع.
2) اضغط Add file ثم Upload files.
3) ارفع الملفات الموجودة داخل هذا المجلد (لا ترفع ملف ZIP نفسه).
4) وافق على استبدال الملفات القديمة إذا ظهرت رسالة بذلك.
5) اضغط Commit changes ثم افتح الموقع واضغط Ctrl+F5.

الملفات:
- index.html: الصفحة الرئيسية وبطاقات المطاعم والكافيهات ونموذج إضافة عرض.
- styles.css: التصميم المتجاوب.
- app.js: فلترة التصنيفات وتجهيز رسالة واتساب.
- manifest.json: إعدادات تعريف التطبيق.

رقم واتساب المشروع مضبوط على: 962778224069

تنبيه:
- نموذج «أضف عرضك» يفتح رسالة واتساب جاهزة ولا يخزن الطلبات تلقائيًا.
- صاحب المحل يجب أن يضغط إرسال داخل واتساب بنفسه.
- لا توجد شراكات أو خصومات مؤكدة ما لم يتم التحقق منها مباشرة.
- تأكد من أرقام المحلات وتفاصيلها قبل الاعتماد عليها.
